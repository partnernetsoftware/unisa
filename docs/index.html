02 / UNISACC

一份编译器，六种目标。

源码仓库 ↗

unisacc 是 neural-network-based compiler：网络权重由 TSV 表 DSL 确定性构造，编译时使用整数网络执行决策。它面向 C99，将源码编译为原生程序。

01

单文件交付

unisacc.com 面向 Linux、macOS、Windows 的 x86-64 与 arm64，共六种目标；所需的内置 C 头文件随编译器交付。

02

直接生成程序

直接写出 ELF、Mach-O 与 PE 可执行文件。默认编译并运行；通过 -o 保存可执行文件，通过 -b 指定目标。

03

自举与可检查的决策

支持编译器自举。网络在声明的有限输入域内逐项校验；固定网络包下的驱动自举与整套网络包重构有各自的验证范围。

构造校验意味着什么？

穷举校验证明网络输出与对应表一致。表是否符合 C99、程序是否正确运行，则由独立的语义与平台测试验证。语言覆盖、库覆盖与已知限制均在产品文档中公开。

03 / 开始使用

下载。编译。运行。

从 UNISA 的 GitHub Releases 获取发行附件、校验信息与版本说明。选择对应发行版，按说明下载 unisacc.com 或 macOS 安装包。

前往发行版 ↗

版本与 SHA-256 索引 ↗

快速开始Linux / macOS 
# 下载后，赋予执行权限
chmod +x unisacc.com

# 将下方示例保存为 hello.c
./unisacc.com hello.c

# 或保存原生可执行文件
./unisacc.com -o hello hello.c
hello.c 
#include <stdio.h>
int main(void) {
    puts("Hello, UNISA!");
    return 0;
}

Windows 请使用发行说明中的启动方式。
