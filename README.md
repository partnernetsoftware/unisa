# UNISA

PartnerNet Software 的 UNISA 产品家族公共发布与索引仓库。

**unisacc** 是 neural-network-based compiler：网络由 TSV 表 DSL 确定性构造，不是训练出来的。

| 目录 | 内容 |
|---|---|
| [`releases/`](releases/README.md) | 按产品组织的发布附件索引；二进制仅存放于 GitHub Releases |
| [`releases/unisacc/`](releases/unisacc/README.md) | unisacc 发布索引 |
| [`releases/ujs/`](releases/ujs/README.md) | ujs 发布索引 |
| [`packages/unisacc/`](packages/unisacc/README.md) | unisacc 包索引格式草案与空模板 |
| [`plugins/agenterm/`](plugins/agenterm/README.md) | agenterm 插件与应用索引格式草案与空模板 |
| `docs/` | 产品网站，由 cdxwjhk-unisa 维护 |
| `papers/` | 论文 |

开发在各产品源码仓库进行；本仓库维护发布元数据与索引，不提交二进制文件。包与插件索引目前为格式草案，尚未声明客户端支持。
